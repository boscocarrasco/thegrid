## Milestone 1 — environment (04:52 UTC)

openbox. Gate (`scripts/verify_env.py`):

Model access resolved in the same milestone (D2.1–D2.3): the `claude` CLI in

into input / output / cache-write / cache-read. A two-turn probe confirmed the

## Milestones 2–3 — observer and executor (05:55 UTC)

`tests/test_id_stability.py` passes: idle, forced repaint and content change
all at 0 % id churn; a window move emits 7 `moved` rather than 7 `removed` +
7 `added`. (The move case reports SKIP when the WM declines the move rather
than asserting nothing.)

It caught two real bugs before anything was built on top:

* **ids chained through the parent's name** — typing one character renames the
  frame `Untitled 1` → `*Untitled 1`, which re-keyed every descendant: 200 %
  churn. Title-bearing roles are now identified structurally.
* **text extraction silently returned empty** — `get_text_iface()` hands back
  the Accessible, whose `get_text()` is the *name* getter with a different
  signature. The whole text-only delta path, i.e. all of arm C, was dead.

## Milestone 6 — pilot (12:40 UTC)

Piloting before spending budget found three blocking faults: Chromium never
launched (needs `--no-sandbox` as root, so every browser task would have
scored zero); the CDP verifier got 403 until the websocket `Origin` header was
suppressed; act-time validation re-walked the whole tree twice per step
(~1.4 s each with Calc open).

## Milestone 8 — full run (12:33–14:10 UTC)

3 arms × 14 tasks × 3 reps = 126 runs, interleaved, all usable, $6.71.

**Arm A was reimplemented partway through and its earlier 14 runs discarded**
(D4.9): the first version accumulated every screenshot in one append-only
conversation, giving the baseline caching the standard loop does not have,
when the brief requires the screenshot to be *replaced* each step. The
corrected baseline records a 20.8 % cache hit rate against 91 % for the tool
arms. Superseded runs are archived in `results/raw/discarded_armA_v1.jsonl`
and excluded from every figure.

## Milestone 9 — analysis (14:25 UTC)

`analysis/aggregate.py` generates every table in RESULTS.md with bootstrap
intervals and says "no difference detectable at this N" wherever intervals
overlap. `analysis/report_numbers.py` prints every figure REPORT.md quotes so
the prose cannot drift from the data.

## Milestone 10 — rigour work with the surplus budget (15:15 UTC)

Two gaps in the first report were worth more than any new feature (D5):

* **Arm D was run** (48 runs). It changed the conclusion: the element table
  alone is not the mechanism — D matches the baseline's success rate at 3.0×
  arm B's cost per completed task, so the *deltas* supply the economics.
* **Two new tasks were added** because the original three non-textual tasks
  were all answerable from the anchor screenshot, so arm B emitted zero crops
  and B/C were identical by construction. The replacements put the decisive
  fact in a mid-task appearance change. Result: **B 8/8, C 1/8**.
* **The equal-budget comparison was run properly**, with the ceiling enforced
  during each run and the step limit doubled so a cheaper arm could spend its
  surplus on steps. This produced the experiment's clearest result: at 8,000
  fresh tokens per task, **B 27/27 against the baseline's 17/27**, intervals
  not overlapping, with the baseline running out of budget in 16 of 27 runs.

## What is still not done, and why

* **Compaction and crop-ageing were never exercised** — tasks run 7–10 steps
  and both need longer horizons. This matters: they are the remedy for the
  tool arms' one clear weakness (4× total tokens).
* **Uncovered changed regions not detected** (D4.8) — hit directly while
  building the new tasks, see D5.3.
* **2 of 16 tasks fail on nearly every arm** (`calc_total` 0/12,
  `cross_report_summary` 1/12); retained rather than dropped after the fact.
* **The vdelta result rests on two tasks**, and how common that task class is
  in real work was not measured.
* **The enforced equal-budget sweep uses one ceiling** (8,000 fresh tokens) on
  a 9-task subset; no sweep across ceilings was run.
